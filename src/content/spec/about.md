# 关于我

你好，这里是 **Vesper**。

这是一个记录技术探索、AI 工具、软件折腾和日常思考的个人博客。这里不追求把每件事都写得特别正式，更希望留下真实、实用、以后还能重新查到的记录。

## 关于本站

本站主要分享以下内容：

- AI 工具和开发工具的使用体验
- 软件配置、效率工具和实用教程
- 前端开发、静态博客和网站搭建
- 日常折腾过程中的经验与问题记录

博客使用 Astro 和 Firefly 构建，文章以 Markdown 的形式维护，并通过 GitHub 自动构建和发布。

## 联系我

你可以通过网站侧栏中的社交链接联系我，也可以在文章评论区或留言板留下想法。

## 最后
